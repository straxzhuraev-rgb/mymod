Мой мод — установка

Что это. Мод работает поверх игры через браузерное расширение Resource Override: расширение подменяет несколько файлов игры на файлы мода. Сами файлы игры не изменяются. Обновления мода происходят на сервере — переустанавливать ничего не нужно.

Установка (4 шага)

  1. Установи расширение Resource Override: Chrome / Firefox.
  2. Нажми кнопку внизу — скачается файл mod-config.ru.
  3. В расширении открой панель и загрузи этот файл (иконка расширения → Import/Загрузить).
  4. Убедись, что правило включено (переключатель on), обнови страницу игры (F5). Если на странице игры появилась кнопка «М» в правом нижнем углу — мод работает.

Настройка под себя

Файл mod-config.ru содержит адрес сервера мода. Если домен или адреса файлов игры изменились — правь его в текстовом редакторе и загружай заново (или правь правило прямо в расширении).

Правило с * в конце матча перехватывает и запросы с параметрами вида core.js?v=123.

Обновление мода

Ничего переустанавливать не надо: исправил файлы на сервере → все игроки получают новую версию при следующем обновлении страницы игры (F5). Если браузер кэширует старый файл — добавь к адресу в replace параметр версии: .../visual.js?v=2.

Что внутри

  • mod/core.js — тема игры + загрузчик модуля (шаблон, замени на пропатченый оригинал)
  • mod/gl-objects.js — загрузчик модуля (шаблон)
  • mod/visual.js — модуль мода (HUD, окно настроек)
  • mod/php/*.php — JSONP-«сервер настроек» (сохраняет настройки в файлы, без БД)
  • saves/ — файлы настроек игроков (два ключа, закрыто от посторонних)
